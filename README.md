# Delhi University Library System (DULS) Website

## How to View on Your Computer
1. Unzip this folder
2. Open the `index.html` file in any browser (Chrome, Edge, Firefox, Safari)
3. Make sure the `images/` folder stays in the SAME directory as `index.html`

## Live Website (Share This Link)


Anyone with this link can view the website from anywhere in the world.

## Files Included
- index.html — Main website
- styles.css — Styling
- script.js — Animations & interactions
- libbot.css — DULS LibBot chatbot styling
- libbot.js — DULS LibBot chatbot logic
- images/ — All photos, logos, and staff pictures from DULS
- README.md — This file
